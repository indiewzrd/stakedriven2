StakeDriven is a fundable poll platform for product validation, mainly for web2/web3 startups. Using web3 fundable polls, your users can stake on what to build next. At the end of a poll, funds from the winning options are transferred to you, while the non-winning voters claim refunds. Iterate with each Agile sprint.

The dapp can be found at https://stakedriven.com/.
